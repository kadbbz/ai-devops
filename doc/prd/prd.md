# 需求与版本工作台 PRD

2026-10-07。产品边界以最新 spec 为准。

1. 一个账号登录；默认 admin/admin，每次默认密码登录都提示且可本次忽略。
2. 管理员可以在技能库上传和编辑技能包。技能包必须包含 `SKILL.md`；模板编辑页必须填写 `agent.md` 并选择技能清单。创建项目时选择模板，初始仓库写入 agent.md、skill/manifest.json 和所选技能目录；仓库标识可自动生成。创建页也可切换“导入压缩包”，任意后缀选择压缩包，识别 ZIP/TAR 内容，校验根 agent.md；不要求环境、命令、Runner、配置版本。导入失败保留表单并给出明确原因。
3. 需求页展示卡片、状态和优先级，可筛选、创建和编辑。详情展示正文、关联分支和版本，直接记录状态，无审批步骤。
4. 分支与合并页展示真实分支和 PR。从当前 main 创建分支，可关联需求；PR 独立详情显示真实差异和源/目标提交。无冲突时按固定 SHA 合并；有冲突时由 DevOps Agent 列出冲突文件、摘要及左右提交内容，人类逐项选择左侧 main 或右侧工作分支，页面只记录选择，不提供合并按钮，IDE Agent 解决后重新推送。不要求测试或构建证据。
5. 版本页展示不可变 tag、提交和变更说明，关联需求；创建版本从 main 固定提交登记，不显示部署成功等虚构结果。
6. 项目与授权保留名称、成员、IDE/DevOps agent 委托。IDE agent 负责代码、测试编写与执行及发布；DevOps 只处理需求和版本。页面给出 Git 网关及共享文件同步用法。
7. 审计记录谁变更需求、分支、PR、tag 和权限。系统运维只管理平台自身 data/backup、冷备和恢复。
8. 紫色、卡片、独立页面，桌面与390px窄屏可用；无 Gate、签发、测试任务、发布任务、Runner 接入配置。
